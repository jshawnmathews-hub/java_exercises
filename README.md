# java_exercises
Use of scanners to input values, basis arithmetic operations, datatypes, contstants, variables declaration, printing results, if-else statements, while loop, switch statements, java.lang.Math class, for loop, nested loops, Random class, Pattern Printing, Inheritance and a Calculator created using JFrame of Swing.


Prerequisites

Before running this project, ensure you have the following installed:


• Java Development Kit (JDK 8 or higher)
• IDE: IntelliJ IDEA, Eclipse, or VS Code (Optional)
